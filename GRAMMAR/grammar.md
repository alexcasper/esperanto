# La Gramatiko de Esperanto — A Grammar Guide
*Node j1 (Lancelot) · milestone GRAMMAR · SKL-8m1r.4 · corpus: RAW/ (PG texts)*

## 1. Fundamentoj — Fundamentals
Esperanto has **no grammatical irregularity**. Core rules (La 16 Reguloj, Zamenhof 1905, fixed by the *Fundamento de Esperanto*):

1. No indefinite article; **la** = the only article (invariable).
2. Nouns end **-o**; plural **-j**. *libro* → *libroj*.
3. Adjectives end **-a**, agree in number: *belaj libroj*. Case: accusative **-n** (rule 2 applies to all case uses).
4. Numerals invariable: unu, du, tri, kvar, kvin, ses, sep, ok, naŭ, dek, cent, mil.
5. Personal pronouns: mi, vi, li, ŝi, ĝi, ni, vi, ili, si (reflexive); possessives + *-a*: mia, via…
6. Verb endings: **-i** infinitive, **-as** present, **-is** past, **-os** future, **-us** conditional, **-u** imperative/jussive.
7. Adverbs: **-e** derived; comparison *pli… ol*, *plej*.
8. Prepositions govern the nominative.
9. Every word reads as spelled (see §5).
10. Accent always on the penultimate vowel: *li-BRO*, *ES-pe-ran-to*.
11. Compounds: root + grammatical ending; head-final (*skribi-tablo* → *skribotablo*, writing-table).
12. Negation with **ne** before the negated word; *nenio* double-negatives are normal.
13. Direction: *-n* after place words = motion toward (*domon*).
14. Every preposition has a definite meaning; if unclear, use *je* (indefinite).
15. Foreign words adopt Esperanto spelling + endings (*ŝtono* ← Stein).
16. The final vowel of nouns/adjectives may be elided before vowel-initial words (*bel’ ulo*), replaced by an apostrophe.

> Fundamento is unchangeable (*neŝanĝebla*): grammar innovation extends usage, never breaks these rules.

## 2. Morfologio — Morphology (affix inventory)
Root + ending + up-to-many affixes; every morpheme is an independent word.

| Affix | Meaning | Example |
|---|---|---|
| **mal-** | opposite | *bona* good → *malbona* bad |
| **re-** | again/back | *relegi* reread |
| **bo-** | in-law | *bopatrino* mother-in-law |
| **dis-** | apart | *disigi* scatter |
| **ek-** | inchoative | *ekridi* burst out laughing |
| **eks-** | former | *eksprezidento* |
| **fi-** | pejorative moral | *fivorto* filthy word |
| **ge-** | both sexes together | *gepatroj* parents |
| **pra-** | ancestral/primeval | *prahomo* |
| **-ĉj-/-nj-** | diminutive names | *paĉjo* dad, *panjo* mom |
| **-in-** | feminine | *patrino* mother |
| **-ul-** | person with trait | *junulo* youth |
| **-ej-** | place | *lern-ejo* school |
| **-il-** | tool | *tranĉ-ilo* knife |
| **-aĵ-** | concrete thing | *manĝaĵo* food |
| **-ec-** | abstract quality | *bel-eco* beauty |
| **-ad-** | continued action | *legado* reading |
| **-ar-** | collective | *arbaro* forest, *vortaro* dictionary |
| **-uj-** | container/country | *cigaredujo*, *Francujo* |
| **-ist-** | professional | *instruisto* teacher |
| **-an-** | member | *klubano* |
| **-em-** | tendency | *laborema* industrious |
| **-ind-** | worthy | *leginda* worth reading |
| **-ebl-** | possible (-able) | *legebla* readable |
| **-ig-** | causative (make) | *beligi* beautify |
| **-iĝ-** | inchoative (become) | *iĝi feliĉa* |
| **-at-/-it-/-ot-** | participles passive (being/done/to-do) | *legata, legita, legota* |
| **-ant-/-int-/-ont-** | participles active | *leganta, leginta, legonta* |
| **-end-** | obligatory | *pagenda* payable |

Participles + *esti* form complex tenses: *mi estas leginta* "I have read"; with -n they become adverbs: *leginte la leteron, li foriris* "having read the letter, he left" (see RAW/pg-17482.txt for prose examples).

## 3. Sintakso — Syntax
- **Word order is free; the default SVO.** The accusative marks objects, so case—not position—carries roles: *La knabo amas la hundon* = *La hundon amas la knabo*.
- Adjectives may precede or follow nouns (preposed is neutral prose style).
- Questions: **Ĉu** + declarative, no inversion: *Ĉu vi venas?* WH-words keep position: *Kiu venis?*
- **La tabelvortoj (correlation table)** — one paradigm of 45:

| | indef | interrog/dem | demonstr | indef-distr | neg |
|---|---|---|---|---|---|
| thing | io | kio | tio | ĉio | nenio |
| person | iu | kiu | tiu | ĉiu | neniu |
| place | ie | kie | tie | ĉie | nenie |
| time | iam | kiam | tiam | ĉiam | neniam |
| kind | ia | kia | tia | ĉia | nenia |
| way | ial | kial | tial | ĉial | nenial |
| reason | iel | kiel | tiel | ĉiel | neniel |
| quantity | iom | kiom | tiom | ĉiom | neniom |

- Clauses: relative *kio/kiu*; conjunctions *ke* (that), *ĉu* (whether), *se* (if); purpose *por ke* + imperative *-u* (*Mi venis, por ke vi sciu*).
- Reflexive *si* only for 3rd-person subjects: *Li lavas sin* vs *Mi lavas min*.
- Direct object of motion uses -n (rule 13): *Li iris Parizon.*

## 4. Fonologio kaj Ortografio
One letter = one sound (rule 9). Vowels a e i o u (pure, Italian-like). Consonants as in English except: **c** = ts, **ĉ** = ch, **ĝ** = j in *jam*, **ĥ** = Scots ch, **ĵ** = zh, **ŝ** = sh, **ĵ/ŭ**: *aŭ/eŭ* are diphthongs (ŭ never syllabic). **H**-series distinguishes meaning: *ĉasio/kaŝo*. Stress penultimate (rule 10): *TA-blo*, *ra-DI-o* (i-o = two vowels → stress -di). Orthography: Latin letters + ĉ ĝ ĥ ĵ ŝ ŭ; ASCII fallbacks cx gx hx jx sx ux.

## 5. Pragmatiko kaj Registro
- **Saluton / Ĝis (revido)** greet/farewell; **Bonvolu** softens requests; **Dankon / Bedaŭrinde** thanks/regret.
- Register is mostly neutral: no T/V distinction (*vi* for everyone). Politeness via phrasing: *Ĉu vi povus…?* (could you…), *Mi ŝatus…* (I'd like).
- Formal vs familiar: technical prose favors SVO + preposed adjectives; poetry freely reorders (rule 3 permits).
- Word-formation economy: prefer affix compounds over borrowed words (*malsanulejo*, not *hospitalo* — though both exist).
- *Zamenhofa* style (see RAW corpus) is the prose reference; modern usage (La Vortoj de PIV, PMEG) elaborates without contradicting the Fundamento.
